EUDR GeoJSON validator

Checks a geolocation file against the European Commission's EUDR GeoJSON File Description, and against the definition of geolocation in Article 2(28) of Regulation (EU) 2023/1115, before the file is submitted. Errors breach the description; warnings mark what passes the rules and is still probably wrong, such as coordinates entered latitude first.

Your file stays in this browser tab. The checks run here, in Python compiled to WebAssembly (Pyodide): the first check downloads Python, up to 14 MB, from jsDelivr, and the validator's source from this site. None of these requests carries any part of your file. The plots are drawn without a map background, so no map server learns where they are.
